What it does

Press F5 and the crosshair detaches from the camera — sweep it across the screen like the original System Shock (1994), while the view edge-pans when you push the reticle to the border. Toggle back to standard mouselook any time.

Install process

  1. Drop FreelookLoader.exe, Launch Freelook.bat, FlatAim.dll and flataim.ini into the game folder.
  2. Drop flataim.kpf into the mods folder.
  3. Launch via Launch Freelook.bat (or FreelookLoader.exe).
  4. Existing save? Run FreelookSavePatcher.exe — pick your saves by name; originals are backed up automatically.

Full details, keybind table and troubleshooting in the README.

Changelog

v1.0.2 latest

  • Fixed switches/keypads that wouldn't frob from one side — the free-aim selection's “is it in front of you?” test now allows a tolerance, so both sides work.
  • Fixed the wrench (and melee) blocking ALL frobbing after using Freelook — your own weapon mesh is now excluded from the frob pick.
  • Fixed a framerate hitch & console churn from the bridge echoing every update (now silent); items un-frobbable in normal play after Freelook; and reload animations now play on the Freelook weapon. Archetype-family frob detection added too.
  • New feel options (all opt-in): hide_crosshair_idle, edge_pan_press_type=hold_pan, edge mouse-delta, weapon_recenter_on_release, and weapon_center (SS1-style centered gun).

v1.0.1

  • Fixed launch failures on some Steam setups (“Injection failed”). The loader now follows Steam's process relaunch and flags Administrator/elevation mismatches, and writes a freelookloader.log for diagnosis. Single-file update — just replace FreelookLoader.exe.
  • Fixed freelook_press_type=hold and edge_pan_press_type being ignored when the .ini line carried a trailing ; comment.
  • New weapon_view_rotate — set to 0 to keep the gun model in its rest pose while your aim still tracks the crosshair.

v1.0.0

  • Initial release — free-aim crosshair, edge-pan view follow, all weapons + melee (wrench included), projectile & muzzle FX, and a resolution-independent HUD.
