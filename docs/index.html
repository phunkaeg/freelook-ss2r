What it does

Press F5 and the crosshair detaches from the camera — sweep it across the screen like the original System Shock (1994), while the view edge-pans when you push the reticle to the border. Toggle back to standard mouselook any time.

EVERYTHING AIMSGuns, projectiles, melee (wrench included), muzzle flash and object selection all follow the free crosshair.
ANY RESOLUTIONThe HUD space is auto-calibrated at runtime. 1080p to ultrawide — dead centre, every time.
NO FUSSLoader included — no manual injection. Steam launch-options support. Save patcher with automatic backups.
REBINDABLEToggle on any key or mouse button via flataim.ini — keybind table in the README.

Install in two minutes

  1. Drop FreelookLoader.exe, Launch Freelook.bat, FlatAim.dll and flataim.ini into the game folder.
  2. Drop flataim.kpf into the mods folder.
  3. Launch via Launch Freelook.bat — or set Steam Launch Options to "...\FreelookLoader.exe" %command% and press Play forever after.
  4. Existing save? Run FreelookSavePatcher.exe — pick your saves by name; originals are backed up automatically.

Full details, keybind table and troubleshooting in the README.
